# Máquina Virtual Azure
Los pasos que sigo para intentar instalar la máquina virtual en Azure.
```mermaid
flowchart TD
A[Primero accedemos a Azure]-->B[Le damos a crear un  recurso]
B-->C[En Buscar servicios y marketplace escribimos Windows server]
C-->D[Donde aparece Windows Server le damos a la flecha que tiene a la derecha, en la cual se desplegará un menu de selección de tipo de Windows]
D-->E[Seleccionamos Windows Server 2019 Datacenter]
E-->F[Le pones el nombre que quieras y seleccionas una región recomendada]
F-->G[Luego en la opción de almacenamiento seleccionamos la más pequeña posible]
G-->H[Pones el nombre de usuario que quieras y una contraseña que cumpla con los requisitos y le das a revisar y crear]
H-->I[Me da error]
```
